# Crop catalog sources

Catalog: `data/crops/catalog.json` (types in `src/lib/crops/types.ts`, loader in `src/lib/crops/catalog.ts`). Compiled 2026-11-14 for the California Delta / Central Valley. Every value below was read from a document fetched during compilation and re-checked against a second fetch. A value that could not be read is `null` (shown as **unknown**) and the crop is excluded from the replay (`isCropUsable`).

## Status

A crop is usable when every water parameter is sourced: Kc ini/mid/end, the four stage lengths, and the planting window start, end and default date. The heat threshold is optional, because it only feeds the hot-day count, which is shown for information and never changes the water result. When a crop has no sourced heat threshold, the app shows "Heat threshold: unknown (no sourced value), so hot days are not counted for this crop" and its hot days are reported as unknown (null), never as 0 and never with a guessed threshold.

| Crop | Usable in replay | Missing |
|---|---|---|
| Winter wheat (`winter-wheat`) | yes | - |
| Maize (grain corn) (`maize-grain`) | yes | - |
| Cotton (`cotton`) | yes | - |
| Rice (paddy) (`rice`) | yes | - |
| Sunflower (`sunflower`) | yes | - (heat threshold unknown: hot days not counted) |
| Sugar beet (autumn-planted) (`sugar-beet`) | yes | - (heat threshold unknown: hot days not counted) |
| Dry bean (`dry-bean`) | no | planting.windowStart, planting.windowEnd, planting.defaultDate |

## Crops excluded and why

- **Sunflower**: heat threshold unknown (not in Luo 2011 or Hatfield & Prueger 2015; the other candidate reviews could not be opened). All other values are sourced.
- **Sugar beet**: heat threshold unknown, same reason. Also uses the "Calif. Desert, USA" September row of Table 11 because it is the only California row whose planting month matches the NASS California window.
- **Dry bean**: planting window and default date unknown. NASS has no California dry-bean row; FAO-56 prints only the month "June". Heat threshold (32 C) is sourced.
- **Tomato (processing)** and **safflower** were considered and dropped: tomato has no failure-point or daily-maximum threshold in Luo 2011 (only fruit-set at 32/26 C day/night versus 28/22 C) and Table 12 prints Kc end as a range with no condition (0.70-0.90); safflower has Table 11 and 12 rows but no NASS California row and no heat threshold in the sources opened.

## Known approximations

- **Climate adjustment of Kc is NOT applied.** FAO-56 Table 12 Kc values are for a sub-humid climate with RHmin about 45 percent and wind speed u2 about 2 m/s. FAO-56 equation 62 adjusts Kc mid (and Kc end when it is above 0.45) for other RHmin, wind speed and crop height. The catalog stores the tabulated values and the replay engine uses them as printed. Equation 62 adds [0.04 (u2 - 2) - 0.004 (RHmin - 45)] (h / 3)^0.3 to the tabulated Kc mid, so Kc mid rises when the air is drier (lower RHmin) or windier (higher u2) than the table's reference, and the effect grows with crop height h. The hot, dry Central Valley summer is drier than the reference, so for the tall crops (maize 2 m, cotton 1.2-1.5 m) the adjustment is expected to be positive and the tabulated value to understate true crop water use. FAO-56 itself shows wheat Kc mid ranging from 1.02 (humid, calm) to 1.25 (arid, strong wind) around the tabulated 1.15. The likely direction of the error is therefore that the replay understates water demand and is, if anything, optimistic about whether a rotation survived. No magnitude is computed here because no local RHmin or wind figures were sourced for this catalog.

- **Kc ini** is a generic value for typical wetting; it can be 0.15 or lower for infrequent wetting or 1.0 or more under frequent irrigation (FAO-56 Table 12 footnote 1, Box 15 for dry beans). Group-level Kc ini values are used where the crop row is blank.
- **Ranged Kc values**: where Table 12 prints a range with no stated condition (cotton mid and end, rice end) the higher printed value is used. Where a footnote defines the condition, the footnote is followed and recorded (wheat end, maize end, sunflower mid, sugar beet end).
- **Stage lengths** are single indicative values from FAO-56 Table 11 ("indicative of general conditions ... may vary substantially from region to region, with climate and cropping conditions, and with crop variety"). Real fields vary by variety, planting date and year. The rice row is from the Mediterranean / May reading of a merged cell, and the sugar beet row from the California Desert row.
- **Planting dates** are state-level NASS usual dates (California as a whole, 2009 data / 20-year progress), not Delta-specific. Default dates inside the window are chosen to be consistent with the planting month printed in the Table 11 row used.
- **Heat thresholds** come from a literature review (Luo 2011) quoting experiments, mostly controlled-environment and mostly tied to a sensitive stage (anthesis, pollen viability). They are applied by the engine to daily maximum air temperature at any point in the season, which is a simplification, and the cotton, rice and dry-bean values are failure-point (Tfp) values whose exact day/night/mean basis the review does not state. The review's values for wheat, maize and rice are all 35 C, but they refer to different mechanisms (see each crop's note).

### Crops left out

- **Chickpea / garbanzo**: Table 12 has Kc (Chick pea, Grabanzo) but Table 11 has no chickpea row, so stage lengths cannot be sourced.
- **Canola / rapeseed**: Table 12 has Kc but Table 11 has no rapeseed or canola row.
- **Quinoa**: not in Table 11 or Table 12.
- **Sugar cane**: Table 11 seasons are 280-720 days (virgin and ratoon crops); not a single annual season.
- **Alfalfa, orchards, vines**: perennials, out of scope for a one-season replay.
